    Speakers & overlap

    Who spoke when, and over whom.

    Speaker turns may overlap, just like real conversations. Omni Studio separates the clean, single-speaker speech of every person from the moments two people talk at once.

    • Pure speech per speaker, ready for speaker verification or voice data.
    • Overlaps labelled with the speaker pair, e.g. SPEAKER_0 + SPEAKER_1.
    • Speaker clips export: one folder of WAV files per speaker.

    Video & action

    What happens, and when.

    Omni Studio watches a video in short windows and names the action in each one, then fills in the rest of the picture: who is on screen, how they move, and what is going on.

    • Action recognition every few seconds, each window with its own confidence.
    • Shot boundaries, active speaker, person boxes and pose with 17 keypoints.
    • Dense captions, one sentence per event, and deepfake checks per window.

    Workflow

    From raw files to training data in five steps.

    1. 1

      Add your data

      Upload files or whole folders, or link a folder on your disk. Audio, video and images are detected automatically.

    2. 2

      Choose the labels

      Pick tasks from the library or write a prompt. Change the classes and try them on a sample.

    3. 3

      Let the model label

      Built for Qwen3-Omni: every task runs on every file in the background.

    4. 4

      Review and correct

      Start with the least certain labels, fix them by mouse or keyboard, invite reviewers with a link.

    5. 5

      Export

      ELAN, Praat, COCO, RTTM, SRT, CSV, a JSONL training manifest and speaker clips.

    Run it locally

    Free. No account. No cloud.

    Omni Studio is a small Python server and a web page. It runs on your own computer and opens in your browser; nothing is uploaded anywhere.

    • macOS or Linux with Python 3.10 or newer
    • The first start installs everything it needs into a local folder (about a minute)
    • Then open http://127.0.0.1:8710

    Questions, answered.

    Does my data leave my computer?

    No. Omni Studio runs on your machine and keeps every file and label in a local folder. Other people only see a project if you create a share link for it, and only that project.

    Which model does the labelling?

    It is built for Qwen3-Omni. Until the model is connected, a placeholder engine fills the tiers (with real speech timing and placeholder values), so you can already try the whole workflow.

    Can I add my own labels?

    Yes. Change the classes and the prompt of any task, or write a new task in plain language. Test it on a few files before running it on everything, and reset to the default any time.

    Can other people help review?

    Yes. A share link opens one project in any browser, view only or with editing. Edits made through a link carry its name, and you can turn a link off whenever you like.

    Which formats can I export?

    Omni Studio JSON, ELAN, Praat TextGrid, SRT, WebVTT, RTTM, CSV, COCO, a JSONL training manifest and speaker clips (WAV per speaker).

    Does it cost anything?

    No. There is no account, no subscription and no paid service behind it.
